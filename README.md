# EasyType

在家庭 Wi‑Fi 中，用手机为 Windows 电脑补上一块好用的共享文本板和语音输入入口。

EasyType 运行在 Windows 电脑上。手机和电脑通过浏览器访问同一个页面，可以在多个共享板之间切换，也可以把手机语音输入实时发送到电脑当前窗口。最终用户使用单文件 EXE 即可，无需安装 Python、uv 或其他运行环境。

当前开发版本：**v1.3.0**

> [!IMPORTANT]
> EasyType 使用家庭局域网 HTTP，不提供互联网远程访问或端到端加密。请勿将端口映射到公网，也不要用它传输密码、验证码、密钥等敏感信息。

## 功能概览

### 多个共享板

- 默认创建“板 1、板 2、板 3”，最多保留八个共享板
- 支持新建、重命名、删除和快速切换
- 每台设备可以停留在不同的共享板，互不强制跳转
- 所有共享板由电脑持久保存，并实时同步到正在查看相同板的设备
- 其他共享板收到新内容时，标签右上角会显示黄色提示点
- 同时编辑不会静默覆盖；出现版本冲突时由用户选择保留哪一份
- 网络中断时暂存未发送内容，恢复连接后继续同步

### Markdown 编辑辅助

- 在“关于”中按浏览器单独开启或关闭，默认关闭
- 共享内容始终保存为普通文本，不渲染 Markdown
- 回车自动延续 `- `、`1. `、`- [ ] ` 和 `> ` 等常用标记
- 在空列表项上再次回车会退出列表，避免不断生成空标记

### 系统托盘

- 透明背景的 EasyType 图标，不再显示黑色方框
- 右键菜单可打开共享板、启用或关闭开机自启动
- 菜单直接显示当前版本，并可点击 `GitHub` 打开项目主页
- 开机自启动仅写入当前 Windows 用户配置，不需要管理员权限

### 手机直输

- 点击手机页面的波浪图标开启或停止直输
- 支持手机键盘和语音输入，文字会实时模拟到 Windows 当前焦点窗口
- 提供远程退格和回车，未开启直输时也可以使用
- 同一时间只允许一台设备直输，避免多台手机同时操作电脑
- Windows 标准文本控件会优先使用低延迟插入通道，其他窗口自动回退到 Unicode 键盘输入
- 电脑焦点变化、网络断开或长时间没有输入时自动结束直输

### 共享板快捷操作

| 访问端 | 操作 |
| --- | --- |
| 电脑网页 | 复制共享文本、清空当前共享板 |
| 手机网页 | 插入到电脑当前窗口、发送电脑回车、清空当前共享板 |

“插入”和“直输”并不相同：

- **插入**：一次性把当前共享板的完整内容写入电脑当前输入框。
- **直输**：把手机后续输入的变化持续模拟成电脑键盘输入。

## 系统要求

- Windows 10 或 Windows 11
- 手机和电脑连接同一个可信家庭 Wi‑Fi

## 快速开始

### 使用 EXE

1. 从 [Releases](https://github.com/Angelysss/easytype/releases) 下载 `EasyType-<版本>.exe`。
2. 双击运行。首次启动单文件 EXE 时需要几秒钟完成解压。
3. 首次运行会出现一次 Windows 管理员确认。允许后，EasyType 会自动清理会阻止当前程序的冲突规则，并创建仅允许“本地子网 + 当前 TCP 端口”的防火墙规则，不要求用户修改 Windows 网络类别。
4. EasyType 启动后常驻系统托盘。点击托盘图标打开电脑页面。
5. 在电脑页面底部查看手机访问地址，例如 `http://192.168.0.12:5000`。
6. 确保手机连接相同 Wi‑Fi，再用手机浏览器打开该地址。

EXE 不需要 Python、uv 或额外依赖。EasyType 主程序仍以普通用户权限运行，只有配置防火墙规则时请求一次管理员确认。规则适用于公用、专用和未识别网络，但访问来源仍被限制为电脑当前直接连接的本地子网。

当前发布没有商业代码签名证书。Windows SmartScreen 可能显示“未知发布者”，公开分发时建议为 EXE 添加代码签名。

### 从源码运行

需要 Python 3.12+ 和 [uv](https://docs.astral.sh/uv/getting-started/installation/)。

```powershell
git clone https://github.com/Angelysss/easytype.git
cd easytype
uv sync
uv run python main.py
```

也可以在完成 `uv sync` 后双击 `run.bat`，让 EasyType 静默运行在系统托盘。

源码版首次监听局域网时也会请求一次管理员确认，并使用与 EXE 相同的端口防火墙规则。以后如果 Windows 更新、安全软件或手工修改导致规则失效，可以在电脑首页的“访问设置”中点击“修复网络访问”，重新触发管理员确认并重建规则。

## 访问模式

访问模式由运行 EasyType 的电脑统一决定，可在电脑首页的“访问设置”中切换。

| 模式 | 适合场景 | 手机访问方式 |
| --- | --- | --- |
| 配对模式 | 希望分别授权和撤销浏览器 | 先使用五分钟有效的一次性二维码配对 |
| 信任模式 | 完全可信的家庭网络 | 同一局域网内直接打开电脑地址 |

### 配对模式

1. 在电脑页面点击“设备管理”。
2. 点击“生成配对码”。
3. 手机扫描二维码，输入设备名称并完成授权。
4. 以后使用同一个手机浏览器访问时无需再次配对。

每个浏览器都有独立的随机凭证，有效期为 180 天。凭证保存在 `HttpOnly`、`SameSite=Strict` Cookie 中，服务端只保存凭证哈希。换浏览器、清除 Cookie 或使用无痕模式后，需要重新配对。电脑可以查看已授权设备并单独撤销，撤销后对应实时连接立即断开。

### 信任模式

同一家庭私有网络中的设备无需配对即可访问。该模式更方便，但任何连接到同一局域网的设备都可能打开 EasyType，因此只应在完全可信的家庭 Wi‑Fi 中使用。

从信任模式切回配对模式后，未配对连接会立即失效；原有授权记录会保留。

## 使用方法

### 共享板

1. 在手机或电脑上选择一个共享板。
2. 输入内容，停止输入约 200 ms 后自动同步。
3. 另一台设备查看同一共享板时会收到实时更新。
4. 其他共享板收到新内容时，其关闭按钮会暂时变成黄色提示点；进入该板后恢复。

使用标签栏的 `＋` 新建共享板，使用 `✎` 重命名当前共享板。标签右上角的 `×` 用于删除对应共享板，至少会保留一个。

### 插入到电脑

1. 在电脑上点选 ChatGPT、记事本等目标输入框。
2. 在手机共享板中准备好完整文本。
3. 点击手机页面的“插入”。
4. 需要发送时，可以继续点击手机页面的“回车”。

### 直输到电脑

1. 在电脑上点选目标输入框。
2. 手机切换到“直输”。
3. 点击波浪图标，调出手机输入法。
4. 使用键盘或语音输入。
5. 再次点击波浪图标停止直输。

只有波浪图标会切换直输开关，附近的退格和回车不会误触开关。开启直输后不要在电脑端切换输入框或移动焦点，否则会话可能停止。

## 数据与隐私

默认数据目录：

```text
%LOCALAPPDATA%\EasyType
├── state.db        # 共享板、文本、版本和更新时间
├── state.json      # 旧版数据，迁移完成后保留
├── auth.json       # 已授权设备与凭证哈希
├── settings.json   # 当前访问模式
└── firewall.json   # 防火墙规则配置标记
```

EasyType 不会把共享文本、原始设备凭证或完整配对地址写入日志。共享板内容以本机 SQLite 数据库存储，不做磁盘加密；电脑账户或磁盘本身的安全仍由 Windows 负责。

所有状态文件都使用原子写入或 SQLite 事务，服务重启后会恢复最后确认的共享板内容。

## 配置

| 环境变量 | 默认值 | 作用 |
| --- | --- | --- |
| `EASYTYPE_PORT` | `5000` | 修改监听端口 |
| `EASYTYPE_DATA_DIR` | `%LOCALAPPDATA%\EasyType` | 修改数据目录 |

修改端口或升级网络规则版本后，EasyType 会再次请求管理员确认。规则被外部软件删除或覆盖时，可在“访问设置”中手动点击“修复网络访问”。

## 常见问题

### 手机打不开页面

- 确认手机和电脑连接同一个 Wi‑Fi，手机没有切换到移动数据
- 重新启动 EasyType，并允许首次防火墙确认
- 在电脑页面打开“访问设置”，点击“修复网络访问”，按 Windows 提示确认
- 关闭可能隔离局域网流量的 VPN、代理或访客网络
- 重新查看电脑页面底部地址；路由器重新分配地址后，电脑 IP 可能变化
- 不要使用 `127.0.0.1`，该地址只代表当前设备自身

### 同一部手机为什么换浏览器后要重新配对

授权凭证属于浏览器 Cookie，而不是手机型号。不同浏览器、无痕窗口和清除 Cookie 后的浏览器都被视为新的访问端。

### 直输为什么没有进入目标窗口

- 先在电脑上点选目标输入框，再到手机开启直输
- EasyType 默认以普通权限运行，不能向管理员权限运行的程序模拟输入
- 某些自绘输入框不支持快速路径，EasyType 会自动回退到通用键盘输入
- 同一时间只能有一台设备开启直输

### 可以从互联网访问吗

不可以。EasyType 只面向家庭私有局域网，不应配置端口转发、反向代理或公网暴露。

## 开发与测试

安装全部开发依赖并运行测试：

```powershell
uv sync --all-groups
uv run pytest
```

测试覆盖共享板持久化、重命名、数量限制、版本冲突、断线草稿、配对有效期和单次使用、设备撤销、同源和私有网段限制、直输去重与按键操作，以及两个真实 WebSocket 客户端之间的同步。

## 构建 Windows EXE

```powershell
.\build-exe.ps1
```

输出文件位于 `dist\EasyType-<版本>.exe`。网页模板、静态资源和全部运行依赖都会打包进单文件 EXE。

## 主要接口

| 接口 | 作用 |
| --- | --- |
| `GET /api/info` | 版本、运行状态和当前修订号 |
| `GET /api/boards` | 获取共享板列表 |
| `POST /api/boards` | 新建共享板 |
| `PATCH /api/boards/<boardId>` | 重命名共享板 |
| `DELETE /api/boards/<boardId>` | 删除共享板 |
| `GET /api/document?boardId=...` | 获取指定共享板内容 |
| `WebSocket /ws` | 文本同步、共享板事件和直输会话 |
| `POST /api/actions/paste` | 把共享板内容插入电脑当前窗口 |
| `POST /api/actions/enter` | 向电脑当前窗口发送回车 |
| `POST /api/actions/key` | 发送受限的退格或回车 |
| `PUT /api/admin/access-mode` | 本机切换访问模式 |

设备管理和访问设置只允许从运行 EasyType 的电脑访问。旧版无鉴权的任意远程按键接口已经移除。

## 已知限制

- EasyType 不读取 Word、微信等第三方程序输入框中的后续修改
- 直输依赖电脑当前焦点，目标程序切换输入框时不一定能可靠识别
- 直输不能操作权限高于 EasyType 的目标程序
- 同时编辑同一共享板时需要人工处理冲突
- 不提供共享板历史版本、云同步或互联网远程访问
