# EasyType

EasyType 是一个供家庭 Wi‑Fi 使用的双向共享文本板。手机和 Windows
电脑在浏览器中编辑同一份文本，修改会实时同步；也可以把当前文本复制到
Windows 剪贴板，或明确地插入到电脑当前窗口。

> EasyType 使用局域网 HTTP，只适合可信家庭网络。请勿用它传输密码、
> 验证码、密钥或其他敏感内容，也不要把端口转发到互联网。

## 主要能力

- 手机与电脑双向实时同步，输入约 200 ms 后发送
- 服务端版本号与冲突保护，不会静默覆盖另一端修改
- 网络断开后暂存本机内容，重连时自动续传或提示冲突
- 单一共享文本跨重启保留
- 可在配对模式与信任模式之间切换
- 多设备分别配对、单独撤销，配对二维码五分钟有效且只能使用一次
- 显式复制到 Windows 剪贴板、显式发送 `Ctrl+V`
- Windows 托盘常驻，无需管理员权限

## 系统要求

- Windows 10 或 Windows 11
- Python 3.12+
- [uv](https://docs.astral.sh/uv/getting-started/installation/)
- 手机和电脑连接同一个可信家庭 Wi‑Fi

## 安装与启动

首次使用，在项目目录运行：

```powershell
uv sync
```

之后双击 `run.bat`。EasyType 会静默运行在系统托盘中。

也可以在终端启动，便于查看日志：

```powershell
uv run python main.py
```

首次启动时，如果 Windows 防火墙询问网络访问权限，只允许“专用网络”，
不要允许“公用网络”。

## 访问模式

电脑共享文本板首页的“访问设置”提供两种模式：

- **配对模式（默认）**：只有已授权的浏览器可以访问，并可单独撤销设备。
- **信任模式**：同一家庭局域网内的设备无需配对即可访问。该模式下
  电脑首页会显示手机访问二维码，设备管理入口会隐藏，但已有授权记录会保留。

从信任模式切回配对模式后，未配对设备会立即断开，之前已经配对的
设备仍可继续使用。信任模式只适合完全信任的家庭网络。

## 手机配对

配对模式下：

1. 在电脑共享文本板首页点击“设备管理”。
2. 在设备管理页点击“生成配对码”。
3. 手机扫描二维码，为设备命名并授权。
4. 以后手机在同一浏览器中打开该地址即可使用，无需重复配对。

每台设备都有独立凭证。撤销授权后，该设备的实时连接会立即断开。

## 使用方式

- 电脑端：点击托盘图标打开共享文本板；设备管理从首页进入。
- 手机端：配对模式下打开配对后保存的页面；信任模式下直接访问
  电脑的局域网地址。
- 任意一端修改文本，另一端会自动更新。
- 两端恰好同时修改时，同步会暂停并要求选择“采用最新内容”或
  “用本机内容覆盖”。
- “复制”会把完整共享文本写入 Windows 剪贴板。
- “插入”适合从手机点击；点击前请确保电脑目标输入框拥有焦点。
  操作后，共享文本会保留在 Windows 剪贴板。

## 数据与配置

默认数据目录：

```text
%LOCALAPPDATA%\EasyType
├── state.json      # 共享文本、版本和更新时间
├── auth.json       # 设备名称与凭证哈希
└── settings.json   # 当前访问模式
```

服务不会把原始设备凭证、共享文本或配对地址写入日志。

可选环境变量：

| 变量 | 默认值 | 作用 |
| --- | --- | --- |
| `EASYTYPE_PORT` | `5000` | 修改监听端口 |
| `EASYTYPE_DATA_DIR` | `%LOCALAPPDATA%\EasyType` | 修改数据目录 |

## 接口

- `GET /api/info`：服务版本、状态和当前修订号
- `GET /api/document`：当前共享文档
- `WebSocket /ws`：`snapshot`、`update`、`ack`、`conflict` 和错误事件
- `POST /api/actions/copy`：复制当前服务端文本
- `POST /api/actions/paste`：复制当前服务端文本并向当前窗口发送 `Ctrl+V`
- `PUT /api/admin/access-mode`：仅限本机切换访问模式

配对模式下远程设备必须先授权；信任模式下家庭局域网设备可直接访问。
访问设置和设备管理接口仅允许从 `127.0.0.1` 或 `::1` 访问。
旧版无鉴权的 `/type` 和 `/key` 接口已移除。

## 开发与测试

```powershell
uv sync --all-groups
uv run pytest
```

测试覆盖持久化、版本冲突、配对过期和单次使用、多设备撤销、来源与网段限制、
剪贴板操作，以及两个真实 WebSocket 客户端之间的同步。

## 已知边界

- 目前只有一个共享文本板，不提供多文档或历史版本列表。
- 电脑端编辑发生在 EasyType 浏览器页面中；它无法可靠读取 Word、微信等
  任意软件输入框中的后续修改。
- 日常使用按“通常轮流编辑”设计，同时编辑会进入人工冲突处理。
- EasyType 不提供互联网远程访问或端到端加密。
